# rocket-index-game
Rocket Index Master adalah game arcade-strategy web di mana pemain menerbangkan roket untuk mengumpulkan pengganda poin (index multiplier) yang terus naik. Tantangannya adalah menekan tombol Cash Out di waktu yang tepat untuk mengamankan skor sebelum roket meledak secara acak dan menghanguskan poin ronde tersebut.
